# Contributing

Contributions should be practical, specific, and verifiable.

1. Open an issue describing the use case and why it matters.
2. Add a prompt under `prompts/` or a worked example under `examples/`.
3. Include the original assumption, credible counterargument, alternatives, and next action.
4. Clearly distinguish illustrative outputs from executed tests or real outcomes.
5. Avoid secrets, proprietary content, and unlicensed third-party material.

Please keep documentation in English and favor concise, reusable instructions.
